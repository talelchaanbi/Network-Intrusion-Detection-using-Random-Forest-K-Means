# Network Intrusion Detection using Random Forest & K-Means

## 📌 Description
This project applies Machine Learning to detect network intrusions. It uses:
- Random Forest (supervised) for classifying network traffic as normal or attack
- K-Means (unsupervised) for clustering and anomaly detection

**Dataset used:** NSL-KDD  
**Environment:** Kaggle Notebook (no local setup required)

## 🛠️ Kaggle Usage
1. Go to Kaggle → Notebooks → New Notebook  
2. Click “Add Data” → Search for NSL-KDD dataset → Add to notebook  
3. Copy the code into the notebook and run it  
4. Results (metrics and graphs) will appear in the notebook

## 📊 Expected Results
- Random Forest: High accuracy (>90%)  
- K-Means: Visual clusters showing anomalous traffic
